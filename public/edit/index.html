Edit the website

Change the words and photos on the website yourself. Nothing you do here can break it: every change is checked before it goes live, and if something needs fixing, the website stays as it was.

Show Edit buttons on the website Open the editor (opens in a new tab) Hide Edit buttons
  1. 1

    Press Show Edit buttons on the website, just above. The homepage opens.

  2. 2

    Find the thing you want to change and press the ✎ Edit button next to it. The editor opens at the right place.

  3. 3

    Change it and press Save. The website updates by itself in 2–4 minutes.

Made a mistake? In the editor’s menu on the left, under Actions, press Undo my last change.

The Edit buttons are only on this phone or computer, in this browser: visitors never see them. When the editor asks you to sign in (the first time, and again now and then), type your email address and the 6-digit code it sends you — it then opens the screen you asked for. If it opens somewhere else, press the Edit button again.

To add something to a page — some text, a photo, a quote, a button — press its Edit button and use More sections, near the bottom of the page’s screen in the editor (on Home, scroll down past the photos and the page’s words).
