What would you like to change?

Pick one: it opens the editor right where you need it. Nothing you do here can break the website. Every change is checked before it goes live, and if something needs fixing, the website stays as it was.

  • Post an announcementThe thin bar across the top of every page. (opens the editor in a new tab)
  • Add a limited-time specialA drink or bowl that’s only here for a while. (opens the editor in a new tab)
  • Add an eventA run club, collab or pop-up, under “Coming up”. (opens the editor in a new tab)
  • Change opening hours or holiday hoursHolidays first, then the weekly hours. (opens the editor in a new tab)
  • Update the menuPrices and items come from Square: change them there, then press “Refresh menu from Square” under Actions in the editor. (opens the editor in a new tab)
  • Change a photoOpen the photo library, or use the Edit buttons to change a photo right where it sits on the page. (opens the editor in a new tab)
  • Add photos to an albumThe albums on “A Day at Layers”. (opens the editor in a new tab)
  • Change words on a pageTurns on the Edit buttons and opens the homepage.
  • Rearrange the homepageShow, hide or reorder its sections: look for “Page layout”. (opens the editor in a new tab)
  • Make a new pageA whole page of your own, with its own web address. (opens the editor in a new tab)
  • Something elseOpens the editor, with everything in the menu on the left. (opens the editor in a new tab)

To add something to a page — some text, a photo, a quote, a button — press its Edit button and use More sections, near the bottom of the page’s screen in the editor (on Home, scroll down past the photos and the page’s words).

Put this on your phone’s home screen

iPhone: tap the Share button, then Add to Home Screen. Android: tap the ⋮ menu, then Add to Home screen. Next time, one tap opens this page.

Or change it right on the website

Show Edit buttons on the website Open the editor (opens in a new tab) Hide Edit buttons
  1. 1

    Press Show Edit buttons on the website, just above. The homepage opens.

  2. 2

    Find the thing you want to change and press the ✎ Edit button next to it. The editor opens at the right place.

  3. 3

    Change it and press Save. The website updates by itself in 2–4 minutes.

Made a mistake? In the editor’s menu on the left, under Actions, press Undo my last change.

The Edit buttons are only on this phone or computer, in this browser: visitors never see them. When the editor asks you to sign in (the first time, and again now and then), type your email address and the 6-digit code it sends you — it then opens the screen you asked for. If it opens somewhere else, press the Edit button again.
